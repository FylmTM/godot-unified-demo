# Credits

Crypt Crew's art, fonts and sounds come from free packs released under CC0 1.0 (public domain): no credit is
required, and it is given gladly. Everything under `assets/` is a pack's own files, unchanged, with the pack's licence
beside them (and Godot's `.import` file beside each, ours); only the files the game uses are committed
(`docs/ART.md`, Adding an asset).
